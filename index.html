Interoperabilidad con IA

El Estándar WebMCP: Cómo los Agentes Usan tu Hoja

WebMCP (Web Model Context Protocol) es la especificación del W3C que permite a agentes de IA interactuar con aplicaciones web de forma estructurada y segura.

  • Doble superficie: Declarativa vía HTML <form toolname> e imperativa vía window.WebMCP.
  • Schemas Tipados Draft 2020-12: Validación estricta A1 regex para celdas y matrices 2D tipadas en outputs.
  • Auditoría & Logs: Registro cronológico de duración, parámetros y resultados disponible para depuración.

Capacidades de Cálculo

Más de 30 Funciones Nativas

Un motor de análisis léxico y sintáctico con precedencia de operadores estándar y propagación precisa de errores.

SUM(rango, ...) Math

Suma todos los números del rango o argumentos.

=SUM(A1:A10) → 450
AVERAGE(rango, ...) Math

Calcula el promedio aritmético de los valores numéricos.

=AVERAGE(B1:B5) → 85.4
ROUND(num, decimales) Math

Redondea un número a la cantidad de decimales indicada.

=ROUND(3.14159, 2) → 3.14
IF(cond, val_si, val_no) Logic

Evalúa una condición lógica y bifurca el valor devuelto.

=IF(A1>100, "Alto", "Normal")
AND(val1, val2, ...) Logic

Retorna TRUE si todas las condiciones lógicas son verdaderas.

=AND(A1>0, B1<10) → TRUE
VLOOKUP(clave, matriz, col, [ord]) Lookup

Busca verticalmente un valor en la primera columna y devuelve otra.

=VLOOKUP("ID45", A1:D20, 3, FALSE)
INDEX(rango, fila, [col]) Lookup

Devuelve el valor en la intersección de fila y columna.

=INDEX(A1:C10, 2, 3)
MATCH(clave, rango, [tipo]) Lookup

Encuentra la posición relativa de un elemento en un vector.

=MATCH("Q3", A1:A12, 0) → 7
CONCATENATE(t1, t2, ...) Text

Une múltiples cadenas de texto o celdas en una sola.

=CONCATENATE(A1, " - ", B1)
TODAY() / NOW() Date

Retorna la fecha o fecha con hora actual formateada ISO.

=TODAY() → 2026-09-07
COUNTIF(rango, criterio) Math

Cuenta las celdas que cumplen un criterio específico.

=COUNTIF(C1:C50, ">100")
SUMIF(rango, crit, [r_suma]) Math

Suma condicional basada en el criterio de prueba.

=SUMIF(A1:A20, "Ventas", B1:B20)

Integridad y Verificabilidad

Gobernado por KDD & CCDD

Desarrollado bajo la metodología MauricioPerera/KDD (Knowledge-Driven Development) y Contract-Driven Development.

Pilar 1

Contratos Criptográficos

Cada módulo (Store, Engine, DAG, Hypermedia Router, WebMCP Bridge) está blindado por contratos con oráculos de pruebas congelados y verificación SHA-256 en CI/CD.

Pilar 2

Open Knowledge Format

Toda la arquitectura, modelos de datos y protocolos se documentan en knowledge/ bajo el estándar OKF v1.0.0, permitiendo comprensión instantánea para humanos y LLMs.

Pilar 3

Validación Automatizada

Las suites de validación deterministas ejecutan análisis estático ASCII, linter OKF, chequeo de contratos CCDD y pruebas unitarias completas antes de cada despliegue a GitHub Pages.
